# 2️⃣ 문제 정의 (Problem)

## 패션 이커머스의 핵심 Pain Points

### 소비자 관점
```
🔴 "이 옷이 나한테 어울릴까?" - 불확실성으로 인한 구매 망설임
🔴 "사이즈가 맞을까?" - 반품률 30~40%의 주원인
🔴 "뭘 입어야 할지 모르겠다" - 스타일링 고민
🔴 "매번 비슷한 옷만 산다" - 새로운 스타일 시도 어려움
```

### 판매자 관점
```
🔴 높은 반품률로 인한 물류/재고 비용 증가
🔴 낮은 구매 전환율 (평균 2~3%)
🔴 재방문율 저조 (차별화 부족)
🔴 개인화 추천의 기술적 한계
```

### 시장 데이터
- 온라인 패션 구매 시 **68%가 사이즈/핏 불안** 경험
- 의류 반품률 **30~40%** (오프라인 대비 3배)
- 반품 처리 비용으로 연간 **수조 원** 손실
- 구매 전환율 향상 **1%p = 매출 10% 증가** 효과

# 3️⃣ 솔루션 (Solution)

## 쇼미룩의 3단계 해결책

### Step 1: AI 스타일 컨설팅
```
사용자 입력 → AI 분석 → 맞춤 코디 추천
```
- 체형/키/몸무게 기반 핏 추천
- TPO(출근룩, 데이트룩, 운동룩 등) 맞춤 스타일링
- 10개 스타일 컨셉별 전문가급 조언

### Step 2: 가상 피팅 (Virtual Try-On)
```
내 얼굴 사진 + AI 코디 = 실제 착용 이미지 생성
```
- Gemini 2.5 Flash Image 기반 얼굴 합성
- 체형 맞춤 실루엣 시뮬레이션
- 1분 내 결과 확인

### Step 3: 원클릭 구매 연동
```
마음에 드는 상품 → 딥링크 → 파트너 쇼핑몰에서 구매
```
- 링크프라이스/쿠팡 파트너스 어필리에이트 연동
- 실시간 재고/가격 확인
- 장바구니 담기 기능

## 핵심 기술 구현

### 1. AI 스타일 추천 엔진 (v8.0)
```typescript
// style-recommend Edge Function 핵심 로직
const styleRecommend = async (request) => {
  // 1. 사용자 프로필 분석
  const userProfile = await getProfile(userId);
  
  // 2. 상품 풀 필터링 (1,400+ 상품)
  const products = await filterProducts({
    gender: userProfile.gender,
    budget: request.budget,
    styleTags: request.concepts
  });
  
  // 3. AI 추천 (4개 카테고리 엄수)
  const recommendation = await geminiFlash({
    prompt: buildPrompt(userProfile, products, request.occasion),
    model: "google/gemini-3-flash-preview"
  });
  
  // 4. 피드백 기반 점수 보정
  return applyFeedbackWeights(recommendation);
};
```

### 2. 피드백 기반 학습 시스템
```sql
-- product_feedback_scores 자동 집계 트리거
CREATE TRIGGER update_feedback_scores
AFTER INSERT ON product_feedback
FOR EACH ROW
EXECUTE FUNCTION aggregate_feedback();

-- 점수 가중치
-- Purchase: +0.1
-- Cart: +0.05
-- Like: +0.03
-- View: +0.005
-- Dislike: -0.08
```

### 3. 다단계 캐싱 시스템
```
L1: 브라우저 메모리 (5분)
L2: React Query 캐시 (30분)
L3: style_cache 테이블 (24시간)
L4: 상품 DNA 텍스트 (영구)
```

### 4. 크로스 모델 폴백
```
Primary: Google Gemini 3 Flash Preview
    ↓ (실패 시)
Fallback 1: Google Gemini 2.5 Flash
    ↓ (실패 시)
Fallback 2: OpenAI GPT-5
    ↓ (실패 시)
Fallback 3: 규칙 기반 점수 추천
```
