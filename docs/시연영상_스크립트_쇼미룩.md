# 쇼미룩(ShowMeLook) 서비스 시연 영상 스크립트

> 총 러닝타임: 약 2분 30초 ~ 3분  
> 대상: 초기창업패키지 심사위원 / 투자자 / 일반 시청자  
> 촬영 도구: OBS Studio 또는 Loom (화면 녹화 + 마이크 음성)  
> 해상도: 1920×1080 권장

---

## 🎬 씬 1: 오프닝 (0:00 ~ 0:15)

**[화면]** 쇼미룩 랜딩 페이지 (https://showmelook.com)

**[나레이션]**
> "안녕하세요. AI 기반 개인화 스타일 추천 서비스, **쇼미룩**입니다.  
> 쇼미룩은 사용자의 체형과 취향을 분석해 딱 맞는 코디를 추천하고,  
> 실제 구매 가능한 상품으로 연결해주는 패션 플랫폼입니다."

**[액션]**
- 랜딩 페이지 히어로 영역을 천천히 스크롤
- 스타일 캐러셀이 자동 회전하는 모습 노출

---

## 🎬 씬 2: 핵심 기능 소개 — 랜딩 페이지 (0:15 ~ 0:35)

**[화면]** 랜딩 페이지 아래로 스크롤

**[나레이션]**
> "쇼미룩의 핵심 가치는 세 가지입니다.  
> 첫째, AI가 체형과 스타일을 분석해 **1개의 완성된 룩**을 추천합니다.  
> 둘째, 추천된 상품은 모두 **실시간 구매 가능한 실제 상품**입니다.  
> 셋째, 내 얼굴을 합성한 **가상 피팅 이미지**를 즉석에서 생성합니다."

**[액션]**
- "어떻게 작동하나요?" 섹션까지 스크롤
- 3단계 프로세스(프로필 → 추천 → 구매) 아이콘이 보이도록 노출
- 요금제/등급 섹션도 잠깐 노출 (무료 체험 가능 강조)

---

## 🎬 씬 3: 회원가입 & 프로필 설정 (0:35 ~ 1:05)

**[화면]** 회원가입 → 프로필 설정 페이지

**[나레이션]**
> "서비스 이용은 간단한 회원가입으로 시작됩니다.  
> 이메일 인증 후, 프로필 설정 화면에서  
> **성별, 키, 체중, 체형, 선호 스타일**을 입력합니다.  
> 이 정보가 AI 추천의 핵심 기반이 됩니다."

**[액션]**
1. 랜딩 페이지에서 **"무료로 시작하기"** 버튼 클릭
2. 로그인/회원가입 페이지 노출 (이미 가입된 계정으로 로그인 시연)
3. 프로필 설정 페이지(`/profile/setup`)로 이동
4. 성별 선택 → 키/체중 입력 → 체형 선택 → 스타일 취향 선택
5. **"프로필 완료"** 버튼 클릭

**💡 촬영 팁:** 미리 테스트 계정을 만들어두되, 프로필 설정은 실시간으로 입력하는 모습을 보여주세요.

---

## 🎬 씬 4: 스타일 생성 — AI 추천 & 가상 피팅 (1:05 ~ 1:50)

**[화면]** 스타일 생성 페이지 (`/style`)

**[나레이션]**
> "이제 핵심 기능인 **스타일 생성**을 해보겠습니다.  
> 프롬프트 창에 원하는 스타일이나 상황을 입력합니다.  
> 예를 들어 '주말 카페 데이트에 어울리는 캐주얼 룩'이라고 입력하면..."

**[액션]**
1. 스타일 생성 페이지 진입
2. 프롬프트 입력: **"주말 카페 데이트에 어울리는 캐주얼 룩"**
3. 예산 슬라이더 조정 (예: 15만원)
4. **"내 얼굴로 스타일 생성"** 버튼 클릭
5. 로딩 프로그레스 바가 진행되는 모습 노출 (약 15~30초)

**[나레이션 계속]**
> "AI가 저의 체형과 취향을 분석해서 완성된 코디를 생성하고 있습니다.  
> 동시에 추천 상품도 함께 선정됩니다."

6. **결과 화면**: 생성된 전신 이미지 + 상품 카드 리스트 노출

**[나레이션]**
> "이렇게 **내 얼굴이 합성된 전신 코디 이미지**가 생성되었습니다.  
> 상의, 하의, 아우터, 신발까지 **4개 카테고리**의 실제 상품이 추천됩니다."

---

## 🎬 씬 5: 상품 상세 & 구매 연결 (1:50 ~ 2:15)

**[화면]** 추천된 상품 카드 영역

**[나레이션]**
> "추천된 각 상품은 브랜드, 가격, 사이즈 정보가 표시되며,  
> **'구매하기' 버튼**을 클릭하면 해당 쇼핑몰로 바로 이동합니다.  
> 제휴 링크를 통해 사용자는 추가 비용 없이 구매할 수 있고,  
> 쇼미룩은 소정의 수수료를 통해 수익을 창출합니다."

**[액션]**
1. 추천된 상품 카드 중 하나에 마우스 오버 (호버 효과 노출)
2. **"구매하기"** 버튼 클릭 → 외부 쇼핑몰 페이지로 이동하는 모습
3. (선택) 브라우저 뒤로 가기로 다시 쇼미룩으로 복귀

**💡 촬영 팁:** 외부 쇼핑몰 페이지가 열리는 것만 보여주고, 실제 결제는 하지 않습니다.

---

## 🎬 씬 6: 갤러리 & 공유 기능 (2:15 ~ 2:35)

**[화면]** 갤러리 영역 + 공유

**[나레이션]**
> "생성된 룩은 자동으로 **마이 갤러리**에 저장됩니다.  
> 마음에 드는 코디는 즐겨찾기하거나, SNS로 공유할 수 있습니다.  
> 공유된 페이지에서도 상품 구매 링크가 유지되어  
> **바이럴을 통한 자연스러운 구매 전환**이 이루어집니다."

**[액션]**
1. 갤러리에서 이전에 생성한 룩 이미지 클릭
2. **공유 버튼** 클릭 → 공유 링크 복사 또는 SNS 공유 모달 노출
3. (선택) 공유 페이지(`/look/:id`)를 새 탭에서 열어 비로그인 사용자 뷰 보여주기

## 📌 편집 가이드

- **BGM**: 밝고 경쾌한 배경 음악 (저작권 프리: Artlist, Epidemic Sound 추천)
- **자막**: 나레이션 핵심 문구를 화면 하단에 자막으로 표시
- **전환 효과**: 씬 전환 시 부드러운 디졸브 또는 슬라이드 사용
- **속도**: AI 생성 대기 시간은 2~3배속으로 편집하여 지루함 방지
- **강조**: 핵심 기능(얼굴 합성, 상품 카드, 구매 버튼)에 화면 확대(줌인) 효과 적용
