## 개요

## 핵심 인사이트

### 1인 vs 5,000명 채용 비교

| 지표 | 1인 유지 (12개월) | 5,000명 채용 |
|------|------------------|--------------|
| 최대 누적 손실 | ₩695만 (5개월) | ₩695만 (5개월) |
| 9개월차 누적손익 | +₩305만 | **-₩295만** |
| 12개월 후 월 순이익 | ₩955만 | ₩355만 |
| 12개월 누적 이익 | **+₩2,666만** | **+₩266만** |
| 권장 초기 자본금 | ₩1,000~1,200만 | ₩1,000~1,200만 |

### 현금흐름 패턴
```text
순이익(만원)
  +400 │                              ┌──── +355만
       │                    ┌─────────┘
  +200 │              ┌─────┘
       │        ┌─────┘
     0 ├───BEP──┘
       │   (6개월)    └──채용──┐
  -200 │──────────────────────┴───────
       └─────────────────────────────────
        M1  M3  M5  M7  M9  M11  M12
```

### 채용 시점의 영향
- **M9에서 채용**: 고정비 ₩215만 → ₩815만 (₩600만 증가)
- **일시적 적자 전환**: M9에서 다시 적자 (-₩136만)
- **2인 BEP 재도달**: M10 (7,200명)에서 다시 흑자 전환

## 초기 자본금 권장액

| 시나리오 | 금액 | 근거 |
|----------|------|------|
| **최소 자본금** | **₩700만** | 최대 누적 손실 커버 (5개월차) |
| **안전 자본금** | **₩1,000만** | 최대 손실 + 30% 여유 |
| **권장 자본금** | **₩1,200만** | 최대 손실 + 예비비 (₩500만) |

**결론**: 5,000명에서 채용하더라도 초기 최대 손실 시점(M5)은 1인 운영과 동일하므로, 필요 자본금도 동일하게 **₩1,000~1,200만** 수준입니다. 다만 연말 누적 이익은 1인 유지 대비 크게 감소합니다.

## 기술 구현 계획

### 파일 수정
- `src/pages/Pitch.tsx`

### 변경 내용

1. **새 슬라이드 데이터 추가** (id: 8로 삽입, 기존 8~11 → 9~12로 밀림)

2. **cashflowChartData 배열 추가**
```typescript
const cashflowChartData = [
  { month: 'M1', users: 100, staff: 1, revenue: 21, cost: 224, profit: -203, cumulative: -203 },
  { month: 'M2', users: 250, staff: 1, revenue: 53, cost: 238, profit: -185, cumulative: -388 },
  // ... M3~M8 (1인 운영)
  { month: 'M9', users: 5800, staff: 2, revenue: 1218, cost: 1354, profit: -136, cumulative: -295 },
  // ... M10~M12 (2인 운영)
];
```

3. **새 슬라이드 UI 구성**
   - 4개 카드: 고정비(1인), 고정비(2인), 변동비, 초기자본금
   - ComposedChart: 막대(월별 순이익) + 라인(누적 손익)
   - 월별 손익 테이블

4. **차트 구성**
```text
ComposedChart:
  - X축: M1 ~ M12
  - Y축: 금액 (만원)
  - Bar: 월별 순이익 (양수: primary, 음수: coral)
  - Line: 누적 손익
  - ReferenceLine: y=0 (BEP 기준선)
  - 채용 시점 표시 (M9)
```
