

# /pitch 페이지 수치 재계산 계획 (구매 기반 등급제 반영)

## 변경 배경

현재 /pitch 페이지는 **구독 기반 요금제** (Free ₩0 / Pro ₩4,900 / Premium ₩9,900)를 기준으로 모든 수치가 계산되어 있습니다. 그러나 실제 서비스는 **구매 기반 5단계 등급제** (Free / Bronze / Silver / Gold / Platinum)로 전환되었으므로, 수익 모델과 모든 재무 수치를 재계산해야 합니다.

---

## 수익 모델 변경 요약

| 항목 | 기존 (구독 모델) | 변경 (구매 기반 등급제) |
|------|----------------|----------------------|
| B2C 수익원 | 월정액 구독 (₩4,900 / ₩9,900) | 어필리에이트 수수료 (2.1~4.2%) |
| ARPU 산출 | 구독료 가중 평균 ₩2,100 | 구매 전환율 x 평균 주문액 x 수수료율 |
| 유료 전환 | Free→Pro 15%, Pro→Premium 20% | 무료→첫 구매(Bronze) 전환율 |
| B2B SaaS | 동일 유지 | 동일 유지 |

---

## 신규 ARPU 계산 (핵심 가정)

- 월간 구매 전환율: 사용자의 **25%**가 월 1회 이상 구매
- 평균 주문 금액: **7만원**
- 평균 어필리에이트 수수료율: **3%** (LinkPrice 2.1~4.2%, Coupang 3%)
- **ARPU = 25% x 70,000 x 3% = ₩525/사용자/월**
- B2B SaaS 기여분 포함 시: 약 **₩700/사용자/월** (규모 확대 후)
