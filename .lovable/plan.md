# 애드센스 재승인 통과 계획

거절 사유는 두 가지입니다.

1. **게시자 콘텐츠가 없는 화면에 광고** — 로그인/로딩/404/폼 화면 등에서 광고 스크립트가 로드됨
2. **가치가 별로 없는 콘텐츠(Thin content)** — 쇼미룩은 "도구형 앱"이라 크롤러가 읽을 수 있는 고유 텍스트 콘텐츠가 거의 없음

1번은 이미 `AdSenseLoader`로 페이지 제한이 적용되어 있으므로, 이번 작업의 핵심은 **2번(읽을거리 콘텐츠 확보)** 입니다. 애드센스는 "사람이 읽을 가치가 있는 고유 콘텐츠"를 요구하므로, 광고 노출 페이지에 실제 에디토리얼 콘텐츠를 만들어야 합니다.

## 1단계: 광고 노출 페이지 재정리 (즉시)

현재 허용 목록에서 콘텐츠가 얇거나 광고에 부적합한 경로를 제외합니다.

- 제외: `/pricing`(상업 유도 페이지), `/install`(안내 목적), `/promo`(영상 단독), `/pitch`(투자 자료), `/privacy`, `/terms`(정책 문서)
- 유지: `/` (랜딩), `/community`, `/look/:id`, `/gallery/:userId`
- 추가 예정: 아래 신규 콘텐츠 경로 (`/guide`, `/guide/:slug`)
- 추가 보호: 커뮤니티/갤러리가 **비어 있거나 로딩 중일 때는 광고 스크립트를 주입하지 않음** (콘텐츠가 렌더된 뒤에만 로드)

## 2단계: 고유 콘텐츠 허브 신설 (핵심) — "쇼미가 제안하는" 시리즈

`/guide` 스타일 가이드 섹션을 만들어 실제 읽을거리를 제공합니다. 모든 글은 쇼미룩의 공식 모델 **쇼미(Shomi)** 가 직접 제안하는 1인칭 톤으로 작성합니다.

- `/guide` — 가이드 목록 허브 (쇼미 소개 + 카테고리별 카드)
- `/guide/:slug` — 개별 아티클 (본문 1,500~2,500자, 쇼미 캐릭터 이미지, 목차, 관련 글 링크)

**아티클 초안은 제가 8편 전부 작성합니다.** (제목은 모두 "쇼미가 제안하는 …" 형식)

1. 쇼미가 제안하는 체형별 코디 공식 (여성/남성)
2. 쇼미가 제안하는 퍼스널 컬러별 옷 색상 고르기
3. 쇼미가 제안하는 미니멀 룩 5가지 원칙
4. 쇼미가 제안하는 계절별 레이어링 공식
5. 쇼미가 제안하는 데이트룩·오피스룩·캐주얼룩 조합법
6. 쇼미가 제안하는 비율 보정 코디 (키 커 보이는 법)
7. 쇼미가 제안하는 AI 가상피팅 200% 활용법
8. 쇼미가 제안하는 사이즈 실패하지 않는 법

각 아티클 공통 구조:
- 쇼미의 인트로 한마디 → 본문 3~5개 소제목 → 쇼미의 체크리스트 요약 → "쇼미룩에서 이 룩 만들어보기" CTA
- 쇼미룩의 룩 이미지·상품 카테고리 데이터를 인용해 **다른 곳에 없는 고유 콘텐츠**로 작성
- **글 하단에 항상 쇼미의 SNS 채널 4개 링크 + 해시태그 블록 삽입** (재사용 컴포넌트 `ShomiTagFooter`)
  - Instagram: https://www.instagram.com/showmi.look
  - YouTube: https://www.youtube.com/@showmi_tv
  - TikTok: https://www.tiktok.com/@showmi.look
  - Threads: https://www.threads.net/@showmi.look
  - 해시태그: `#쇼미룩 #ShowMeLook #쇼미 #AI가상피팅 #AI스타일링` + 글별 주제 태그


## 3단계: 기존 페이지 콘텐츠 보강

- **랜딩(`/`)**: 서비스 소개 외에 "쇼미룩 사용법", "AI 스타일링이란", FAQ 섹션 추가 (텍스트 기반, 접기/펼치기)
- **`/look/:id`**: 룩 설명 텍스트(스타일 태그 기반 설명문), 코디 포인트, 관련 룩 추천 섹션 추가 → 현재는 이미지 위주라 thin으로 판정될 소지가 큼
- **`/community`**: 상단에 섹션 소개 문단 + 필터 설명 추가, 목록이 비면 광고 미노출
- **404 페이지**: 주요 페이지 링크 목록 추가 (광고는 계속 미노출)

## 4단계: 크롤링/색인 정리

- `sitemap.xml`에서 `/auth` 등 로그인·유틸 경로 제거, `/guide` 및 개별 가이드 URL 추가
- `robots.txt`에 `/auth`, `/survey`, `/connect` Disallow 추가
- 각 가이드 페이지에 `Article` JSON-LD, canonical, 고유 title/description 적용
- 랜딩 FAQ에 `FAQPage` JSON-LD 적용

## 5단계: 재검토 요청

배포 후 실제 URL에서 콘텐츠가 렌더되는지 확인하고, 애드센스 콘솔에서 검토를 재요청합니다. (승인까지 보통 수일~2주)

## 기술 세부사항

- 아티클은 별도 CMS 없이 `src/content/guides/*.ts` 형태의 타입 지정된 데이터 모듈로 관리하고, `/guide/:slug`에서 렌더
- `AdSenseLoader`에 `ready` 조건 추가: 경로 허용 + 페이지가 "콘텐츠 렌더 완료"를 알린 경우에만 스크립트 주입 (컨텍스트 또는 커스텀 이벤트 사용)
- SEO 태그는 기존 `SEOHead` / `react-helmet-async` 패턴 재사용
- 광고 슬롯(`<ins class="adsbygoogle">`)은 승인 후 가이드 본문·커뮤니티 목록에만 배치
