

# BEP(손익분기점) 분석 슬라이드 추가 계획

## 개요
투자 제안서 `/pitch` 페이지에 **손익분기점(BEP) 분석** 슬라이드를 새로 추가합니다. 이전 대화에서 계산한 BEP 분석 내용을 시각적으로 매력적인 슬라이드로 구현합니다.

## 슬라이드 배치
- **현재**: 10개 슬라이드

- **새 슬라이드 위치**: 슬라이드 7 (시장 분석 다음, 경쟁 우위 이전)

## 기술 구현 상세

### 파일 수정
- `src/pages/Pitch.tsx`

### 구현 방식
1. `slides` 배열에서 슬라이드 7 위치에 새 BEP 슬라이드 객체 삽입
2. 기존 슬라이드 7-10의 id를 8-11로 업데이트
3. 새 슬라이드 콘텐츠를 3개 카드 + 테이블 형태로 구성

### 디자인 스타일
- 기존 슬라이드와 일관된 Tailwind CSS 클래스 사용
- `bg-card`, `border-border`, `rounded-lg` 등 기존 패턴 유지
- 핵심 수치는 `text-primary`, `text-coral`, `text-sky` 등으로 강조
- 그리드 레이아웃: `grid md:grid-cols-3 gap-4`
