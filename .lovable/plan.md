# 상단 헤더 로고 및 정렬 개선

## 변경 내용
- 왼쪽 상단의 한글 워드마크 이미지를 제거하고 쇼미룩 심볼 로고만 남깁니다.
- 로고 영역의 불필요한 음수 여백과 크기 차이를 없애 헤더 항목을 수직 중앙에 정렬합니다.
- 한국어와 영어 선택 시 동일한 로고와 동일한 헤더 배치를 유지합니다.
- 데스크톱과 모바일 메뉴에서 기존 이동 기능과 접근성 문구는 유지합니다.

## 확인
- 한국어/영어 전환 후 로고가 계속 표시되는지 확인합니다.
- 데스크톱과 좁은 화면에서 언어 버튼 및 다른 메뉴와 겹치지 않는지 확인합니다.

## 기술 세부사항
- `MainNavigation`의 로고 묶음을 단일 심볼 이미지 버튼으로 단순화합니다.
- 기존 디자인 토큰과 버튼 컴포넌트는 그대로 사용합니다.
