# 랜딩페이지 마우스 추적 애니메이션 제거

## 현재 상태
- `src/components/LiquidCursor.tsx`: 마우스를 따라다니는 컬러 파티클(물방울) 효과. `src/pages/Landing.tsx`에서만 사용 중.
- 매 프레임(초당 60회) 캔버스 전체를 지우고 수십 개 원을 다시 그리며, SVG blur 필터까지 적용 — 저사양 기기에서 랜딩 체감 속도를 느리게 만드는 주요 원인.

## 작업 내용 (권장: 완전 제거)
1. `src/pages/Landing.tsx`에서 `<LiquidCursor />` 렌더와 import 제거.
2. `src/components/LiquidCursor.tsx` 파일 삭제 (다른 페이지에서 사용하지 않음).
3. 랜딩 페이지가 정상 표시되는지 미리보기로 확인.

## 대안 (원하시면 제거 대신 적용 가능)
- **A. 정지 장식으로 교체**: 애니메이션 대신 화면 구석에 고정된 은은한 컬러 그라데이션 블러 장식(CSS만, 연산 거의 0). 분위기는 유지, 속도 영향 없음.
- **B. 저사양/모바일에서만 끄기**: 터치 기기·배터리 절약 모드·'동작 줄이기' 설정 사용자에게만 자동 비활성화. 데스크톱 고사양에서는 유지.
- **C. 가벼운 버전으로 축소**: 파티클 수와 blur 필터를 줄인 경량 버전. 효과는 남지만 체감 개선 폭은 제한적.

## 확인 방법
- 랜딩 페이지에서 마우스를 움직여 파티클이 사라졌는지 확인.
- 모달 열기/스크롤 등 기존 동작에 영향 없는지 확인.
