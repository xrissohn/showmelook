# 쇼미룩 현재 HEAD 구현 현황 점검 (재지원서용)

코드 수정 없음. 아래 내용은 현재 저장소 파일과 운영 데이터베이스 조회로 확인한 사실만 기재했고, 확인 불가한 항목은 "확인 불가"로 표시했습니다.

## 1) 사진·프로필 → AI 추천 → 가상착장 → 구매 (구현 완료)

- 프로필 설정(성별/키/체중/체형/선호 스타일/얼굴 사진 업로드)과 프로필 편집 화면 운영 중.
- 추천 엔진 `style-recommend`(3,356줄)와 이미지 생성 `generate-style`(1,226줄)이 실서비스에서 동작.
- 얼굴 합성, 전신 3:4 이미지, 생성 대기열(`process-generation-queue`, 1분 주기)까지 가동.
- 구매 연결: 링크프라이스 딥링크 함수 + 구매 성과 수신(`linkprice-postback`), 쿠팡 일일 리포트 자동화, 장바구니/게스트 장바구니 운영.
- 미구현: 구매 직전 품절 재확인(`purchase_check`) 함수는 코드에 존재하지 않음. 대신 매일 상품 상태 점검 배치(`product-health-check`)로 대체 운영 중.

## 2) 상품 데이터·DNA·계절 추천 (구현 완료, 고도화 진행형)

- DNA 자동 생성 배치 2종(10분 주기 + 일 1회), DNA 분류 규칙 관리 화면, 상품 DNA 편집기 운영.
- 계절 필터/가점 로직이 추천 엔진에 실제 반영(계절별 제외·가점 키워드, `season_fit` 기반 필터).
- 상품 수집: 쿠팡 배치(2시간 주기), Bright Data 수집·웹훅, 대기 상품 검수 화면, 색상 자동 분석(10분 주기), 누락 이미지 관리.
- 학습형 개선: 태그 교정 분석, 추천 패턴 일일 학습, 상품 피드백 점수 운영.

## 3) 커뮤니티·공유·추천인·등급/구독·가족 프로필 (구현 완료)

- 커뮤니티 갤러리, 유저별 갤러리, 좋아요, 공개 공유 룩 상세/링크 공유, 크롤러용 공유 프리뷰 및 OG 이미지 자동 생성.
- 갤러리 공개 시 보너스 크레딧 지급(유저당 최대 10) 동작.
- 추천인 코드 발급·적용·보상·성공 메일 발송 운영(코드 60개 발급됨).
- 등급(누적 구매 기반)과 구독 요금제 화면, 일/월 생성 한도 관리 운영. 유료 구독 실적은 현재 2건으로 초기 단계.
- 가족(멀티) 프로필 관리 운영(4건 등록).

## 4) Cafe24 B2B 위젯·테넌트 (구현 완료, 실사용 초기)

- OAuth 설치 인증, 상품 동기화, 위젯 서빙, 웹훅 로그, 관리자 테넌트 관리 화면 모두 존재.
- 전용 테이블 4종(테넌트/상품/피팅 세션/웹훅 로그)과 데모 페이지, 연동 가이드 문서 보유.
- 실사용 지표는 테넌트 3곳·피팅 세션 1건으로 파일럿 단계.

## 5) 쇼미 공식 SNS 채널 팝업·스타일 가이드 (구현 완료)

- 4개 채널(Instagram·YouTube·TikTok·Threads) 정보와 오픈 안내 팝업 운영.
- A/B 설문 메일 발송·응답 집계·채널 소식 메일 발송 및 관리자 패널 운영.
- 스타일 가이드 아티클 8편과 가이드 허브/상세 페이지, 가이드에서 스타일 생성으로 프롬프트 자동 전달 기능 동작.

## 6) MCP·SEO·PWA 등 운영 고도화

- MCP: 읽기 전용 도구 3종(상품 검색/상품 상세/공개 룩 목록) 구현 및 엣지 함수 배포본 존재. 오픈소스 문서 세트(README·SBOM·AI 모델 공개·대회 체크리스트·CI/CodeQL) 완비.
- SEO: sitemap, robots, RSS, 동적 메타·JSON-LD(상품 오퍼에 배송/반품/판매자 정보 포함) 적용. 별점·리뷰 구조화 데이터는 실제 리뷰 데이터가 없어 미적용.
- 관리자 운영 콘솔: 상품/DNA/추천/딥링크/대기상품/이미지/유저/오류/작업/성능/Cafe24/쿠팡·링크프라이스 리포트/Bright Data/헬스체크/유저 분석/태그 교정/설문 등 탭 운영.
- PWA: 현재 서비스워커는 기존 캐시를 지우는 일회성 정리용으로만 남아 있고, 빌드 설정에 PWA 플러그인과 매니페스트 파일이 없습니다. 즉 **오프라인 캐싱형 PWA는 현재 비활성 상태**이며, README의 PWA 서술은 현 상태와 불일치합니다. 설치 안내 페이지는 존재합니다.

## 7) Shopify 연동

- 저장소 전체(소스·엣지 함수·문서·설정·의존성)에서 Shopify 관련 코드·설정이 **전혀 존재하지 않음**. 현재 커머스 연동은 Cafe24(B2B 위젯) + 제휴 링크(링크프라이스·쿠팡) 경로뿐입니다.
