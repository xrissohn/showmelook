# 스타일 가이드 → 프롬프트 자동 입력

가이드 글마다 "쇼미가 제안하는 룩 프롬프트" 2~3개를 추가하고, 사용자가 고른 프롬프트가 스타일 만들기 입력창에 자동으로 채워지도록 연결합니다.

## 동작 흐름

```text
가이드 상세 (예: 체형별 코디)
  └ 쇼미의 추천 룩 3개 (칩/버튼)
      └ 클릭 → /style?prompt=<선택한 프롬프트>
          └ 스타일 만들기 입력창에 프롬프트 자동 입력 + 안내 토스트
```

## 변경 내용

1. **가이드 데이터 확장**
   - `src/content/guides/types.ts`에 `lookPrompts: { label: string; prompt: string }[]` 필드 추가(선택 필드로 두어 기존 글 호환).
   - 8개 가이드 글 각각에 그 글의 핵심 원리를 반영한 프롬프트 2~3개 작성.
     예) 체형별 코디 → "어깨가 넓은 체형, 브이넥 니트와 스트레이트 슬랙스, 차분한 톤"

2. **가이드 상세 페이지 (`src/pages/GuideDetail.tsx`)**
   - 기존 "쇼미룩에서 이 룩 만들어보기" 버튼 자리에 쇼미의 추천 룩 카드 섹션 배치.
   - 각 항목은 라벨 + 실제 프롬프트 미리보기를 보여주고, 클릭 시 `/style?prompt=...` 로 이동(프롬프트는 URL 인코딩).
   - 프롬프트가 없는 글은 기존처럼 `/style` 로만 이동하는 버튼 유지.

3. **스타일 만들기 (`src/pages/StyleGenerator.tsx`)**
   - 기존 `searchParams` 를 그대로 사용해 `prompt` 파라미터를 읽고, 최초 마운트 시 `customStylePrompt` 에 주입.
   - 입력창은 편집 가능 상태 그대로 유지, 자동 생성은 하지 않음(사용자가 생성 버튼을 눌러야 실행).
   - 길이 제한(예: 300자)으로 잘라 안전하게 처리, 파일 대규모 수정 없이 최소 삽입만 진행.

## 기술 메모

- `StyleGenerator.tsx`는 리팩터링 금지 원칙에 따라 상태 주입용 `useEffect` 하나만 추가합니다.
- 프롬프트는 한국어 문장이므로 링크 생성 시 `encodeURIComponent` 사용.
- 가이드→스타일 이동 시 `tab` 파라미터는 기본값(생성 탭) 유지.
