# 영어 화면 번역 정합성 개선

## 목표
영어 선택 시 스타일 만들기와 연결 화면에 남아 있는 한글 버튼, 멤버십 등급, 로딩·대기·알림 문구를 영어로 일관되게 표시합니다.

## 변경 범위
- 스타일 만들기의 생성 대기 화면, 이미지 상태, 저장·공유, 상품 및 갤러리 알림에 언어별 문구 적용
- 멤버십 등급 배지와 혜택 설명을 한국어/영어로 분리
- 스타일 화면에서 사용하는 선택지, 기본 사용자명, 오류·완료 메시지의 영어 표시 보완
- 공용 화면에서 영어 모드에 노출될 수 있는 하드코딩 한글도 함께 점검

## 검증
- 영어로 전환한 상태에서 스타일 만들기 초기 화면과 생성 대기 화면 확인
- 멤버십 등급, 저장·공유 메뉴, 주요 버튼과 알림에 한글 잔여 문구가 없는지 확인
- 한국어 화면이 기존과 동일하게 유지되는지 확인
- 관련 테스트와 데스크톱·모바일 화면 점검

## 기술 세부사항
- 기존 `LanguageContext`와 번역 사전을 우선 사용하고, 필요한 번역 키만 추가합니다.
- 대규모 스타일 생성 파일은 구조를 바꾸지 않고 문구 분기만 최소 수정합니다.
- 데이터 원문, 상품명, 사용자가 작성한 내용처럼 번역 대상이 아닌 값은 변경하지 않습니다.
