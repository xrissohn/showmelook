# 쇼미 챗봇 비용 점검 및 최적화

## 결론부터

**모델은 `openai/gpt-6-astra` 그대로 두는 것을 추천합니다.** 지금 비용이 나오는 곳은 모델이 아니라, **질문 한 번마다 쇼미의 지식 전체(약 12,300토큰)를 함께 보내는 구조**입니다.

오늘(10/4) 실제로 기록된 내역입니다.

| 항목 | 실측 |
| --- | --- |
| 쇼미 챗 요청 수 | 11건 (전부 gpt-6-astra) |
| 오늘 쇼미 챗 총 비용 | 1.915 크레딧 |
| 답 하나당 비용 | 0.058~0.083 크레딧 (지식이 캐시에 있는 경우) |
| 캐시에 새로 저장한 2건 | 0.636 / 0.649 크레딧 (11배 비쌈) |
| 입력 토큰 구성 | 요청당 약 12,269토큰 중 **캐시 입력 12,269 / 새 입력 0~33** |
| 출력 토큰 | 요청당 31~176토큰 (매우 적음) |
| 같은 기간 다른 지출 | 데이터베이스 24.15, 빌드 12.7+5.9+3.0 크레딧 |

也就是说: 챗봇은 오늘 전체 지출의 아주 작은 부분이고, 그 안에서도 **2번의 "캐시 저장"(1.28 크레딧)이 절반 넘게**를 차지합니다. 답변 생성(출력)은 값이 가장 비싼 토큰이지만 양이 적어서 거의 차이가 없습니다.

## 그래서 모델을 바꾸면?

- 답변을 만드는 출력량이작아서, 싼 모델로 바꿔도 줄어드는 금액이 거의 없습니다.
- 반대로 한국어 캐릭터 말투·서비스 안내 정확도는 떨어질 수 있습니다.
- **원하는 모델이 있으면 정확한 이름을 알려주시면 그대로 바꿔드립니다.** 다만 그게 비용을 줄이는 길은 아닙니다.

## 대신 할 일 (비용을 실제로 줄이는 3가지)

1. **지식 파일 줄이기 (가장 효과 큼)** — 쇼미 캐릭터 배경 이야기의 긴 문장을 요약하고, 사용자가 실제로 묻는 서비스·등급·사용법·스타일 가이드 정보는 그대로 남깁니다. 약 12,300토큰 → 6,000토큰 수준.
   - 예상: 답 하나당 0.075 → 약 0.05 크레딧, 캐시 저장 0.64 → 약 0.32 크레딧 (오늘 기준 1.92 → 약 1.2, **추정치**)
   - 트레이드오프: 쇼미의 자기소개가 지금보다 짧아집니다.
2. **언어 안내를 지식 뒤로 옮기기** — 지금은 "한국어로 답해" 문장이 지식 앞에 있어서, 영어 사용자가 처음 질문하면 캐시를 새로 저장해야 합니다(11배 비용). 지식 뒤로 옮기면 한국어·영어 같은 캐시를 씁니다. 답변 품질 변화 없음.
3. **대화 기록을 최근 6개로 줄이기** — 지금은 최근 12개를 보냅니다. 긴 대화에서 입력이 커지는 것을 막습니다.

현재 이미 잘 되어 있는 것: `reasoning_effort: "low"`, 답변 3~6문장 제한, 답변 스트리밍.

## 선택: 품질을 1도 안 잃고 싶다면

1번(지식 줄이기)을 빼고 2·3번만 적용할 수 있습니다. 그러면 오늘 기준 약 1.92 → 1.7 크레딧 수준으로, 줄어드는 폭은 작습니다.

## 기술 상세

- 대상 파일: `supabase/functions/shomi-chat/index.ts`, `supabase/functions/shomi-chat/knowledge.ts`
- `SYSTEM(lang)` 템플릿: `${lang === "en" ? ... : ...}` 줄(19행)을 `=== 지식 ===` 블록(21~22행) **뒤로** 이동 → ko/en이 동일한 캐시 프리픽스 공유.
- `knowledge.ts`(44,430바이트, 약 12.3k토큰)에서 캐릭터 스토리 문단을 압축, 서비스/등급/가이드/FAQ 사실은 전량 유지.
- `src/components/ShomiChatbot.tsx:64`의 `history.slice(-12)` → `history.slice(-6)`.
- 모델 ID(`openai/gpt-6-astra`), `reasoning_effort: "low"`, `stream: true`, CORS/에러 처리는 그대로.
- 캐시 저장 발생 원인: 12:16 → 12:52 사이에 36분 공백 후 발생했고, 두 요청 모두 한국어 프리픽스로 동일했습니다. 즉 언어 전환이 아니라 캐시 유효시간 만료이며, 앱 코드에서 제어할 수 있는 항목이 아닙니다(그래서 프리픽스 안정화만 처리).

## 확인 방법

1. 지식 축약 전/후로 같은 질문 4개(등급, 무료 사용법, 데이트룩, 쇼미 정체)를 물어봐 답변을 비교 — 사실 정보가 빠지지 않았는지 확인.
2. 가장 짧은 답변과 가장 긴 답변이 한 화면에 다 보이는지 확인.
3. 영어로 첫 질문 후 두 번째 질문에서 비용이 캐시 저장 수준(0.6)이 아니라 0.05 수준으로 나오는지 AI 요청 로그로 확인.
4. `npm test`, `git diff --check`, 빌드 확인.
