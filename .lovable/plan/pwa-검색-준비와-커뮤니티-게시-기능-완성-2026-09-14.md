# PWA·검색 준비와 커뮤니티 게시 기능 완성

## PWA와 모바일 빠른 열림
- 기존 쇼미룩 아이콘을 사용하는 웹 앱 manifest를 추가하고 `showmelook.com` 루트에서 열리도록 연결합니다.
- 홈 화면 설치, 앱 이름, 테마색, 세로 화면, maskable 아이콘을 설정합니다.
- 선택하신 범위대로 오프라인 캐시는 추가하지 않습니다. 기존의 오래된 서비스워커 정리 장치는 유지해 흰 화면 재발 위험을 줄입니다.
- 설치 안내 화면의 오프라인 지원 표현은 실제 제공 범위인 빠른 실행·자동 최신 상태에 맞춥니다.

## 검색 노출 기반
- 기존 메타 태그와 페이지별 제목·설명·대표 주소를 점검하고 누락·중복을 정리합니다.
- 기존 정적 sitemap 방식을 유지하면서 공개·검색 가능한 실제 경로와 스타일 가이드 목록을 맞춥니다.
- robots.txt는 검색엔진 허용과 로그인·관리자·개인 화면 제외 정책을 유지하며 sitemap 주소를 확인합니다.
- 임의의 현재 날짜를 sitemap 변경일로 넣지 않고, 기존 값은 출처가 불명확하므로 보존합니다.

## 커뮤니티 게시물 작성·수정·삭제
- 로그인 사용자가 커뮤니티에서 ‘게시하기’를 눌러 자신이 생성한 룩을 선택하고 소개글·태그를 작성해 공개할 수 있게 합니다.
- 공개된 자신의 게시물 상세 화면에서 소개글·태그를 수정하고, 확인 절차 후 게시물을 삭제할 수 있게 합니다.
- 공개/비공개 전환과 기존 공개 보너스 정책을 그대로 연결합니다.
- 본인 게시물 판별은 공개 화면에 개인정보를 노출하지 않고 로그인 사용자의 소유 룩 목록으로 안전하게 처리합니다.

## 상품 추천·공유·등급
- 게시물 상세에서 이미 연결된 실제 추천 상품, 딥링크 구매, SNS/링크 공유 기능을 그대로 노출하고 동작을 확인합니다.
- 커뮤니티 작성 영역에 현재 로그인 사용자의 구매 등급을 표시해 기존 등급 시스템과 연결합니다.
- 다른 사용자가 누른 좋아요 수가 새로고침 후 사라지는 문제를 보안 함수로 수정합니다.

## 보안과 검증
- 작성·수정·삭제는 기존 소유자 전용 접근 정책을 사용하며 타인 게시물 변경을 허용하지 않습니다.
- 좋아요 집계 함수는 로그인 사용자만 호출하고 실제 좋아요 행을 다시 계산하도록 제한합니다.
- 한국어·영어, 데스크톱·모바일, 비로그인·로그인 상태에서 게시·수정·삭제·공유·상품 구매 진입과 설치 정보를 확인합니다.
